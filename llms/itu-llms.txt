# ITU — International Telecommunication Union

> The United Nations specialized agency for information and communication technologies. ITU-R
> allocates the global radio spectrum and manages the master international frequency register,
> ITU-T publishes the Recommendations that define interoperable telecom networks, and ITU-D
> collects and publishes the world's reference ICT statistics. ITU operates two real, publicly
> callable HTTP APIs — the DataHub statistics API and the ITU-D Proximity to Fibre Node API — but
> publishes no developer portal, no OpenAPI, no SDK and no terms of programmatic use for either.

ITU's API posture is an inversion of the usual regulator pattern: the data is genuinely open and
ungated, but the API programme does not exist as a declared product. Both APIs answer anonymously.
The descriptions and artifacts linked below were derived by API Evangelist from live probes of
ITU's own infrastructure; ITU has not published, reviewed or endorsed them.

## APIs

- [ITU DataHub API](https://datahub.itu.int/): The undocumented JSON API behind ITU's official ICT
  statistics portal. Base URL `https://api.datahub.itu.int/v2`. 18 confirmed anonymous GET
  operations covering country and region reference data, the full indicator dictionary, indicator
  time series by country and by regional aggregate, curated dashboards, the ICT Development Index
  (IDI), and the Universal and Meaningful Connectivity (UMC) targets. No key, no login, no rate
  limit published.
- [ITU Proximity to Fibre Node API](https://www.itu.int/en/ITU-D/Technology/Pages/EmergingTechnologiesPages/api.aspx):
  An ITU-D batch geospatial API over the ITU Interactive Transmission Map. Base URL
  `https://bbmaps.itu.int/functionproximity`. POST a `text/csv` body of `X,Y` coordinates and
  receive a URL to a generated ZIP of results. Two routes: proximity band to the nearest fibre node,
  and a within-10km flag.

## Provider-published

- [BBMaps llms.txt](https://bbmaps.itu.int/llms.txt): ITU's own llms.txt for the Broadband Maps
  platform — the single machine-readable, AI-facing document ITU publishes anywhere. Saved verbatim
  in this repo at `llms/itu-bbmaps-llms.txt`.

## Docs

- [ITU DataHub](https://datahub.itu.int/): the portal the DataHub API serves. No API tab, no developer section.
- [ITU-D "API - Proximity to Fibre Node"](https://www.itu.int/en/ITU-D/Technology/Pages/EmergingTechnologiesPages/api.aspx): the only ITU page that presents an API to the public.
- [ITU Interactive Transmission Maps](https://www.itu.int/en/ITU-D/Technology/Pages/InteractiveTransmissionMaps.aspx): the Broadband Maps programme behind the Proximity API.
- [ITU-T Recommendations](https://www.itu.int/en/ITU-T/publications/Pages/recs.aspx): ITU's telecom standards, published as PDF only — no OpenAPI, no JSON Schema.
- [ITU-D statistics reports](https://www.itu.int/itu-d/reports/statistics/): the reference publications built on the DataHub data.
- [ITU Hub](https://www.itu.int/hub/): ITU news and blog.

## Absent

ITU publishes none of the following, verified 2026-07-26: developer portal (developer.itu.int,
developers.itu.int, docs.itu.int and api.itu.int do not resolve), OpenAPI or Swagger, SDKs on npm /
PyPI / Maven / NuGet, a CLI, webhooks or AsyncAPI, GraphQL, gRPC, a Postman workspace, a status
page, a changelog, a deprecation policy, an SLA, published rate limits, a security.txt, a
vulnerability disclosure programme, a trust center, or any public repository in its official GitHub
organization (github.com/ITUINT, 0 public repos).
